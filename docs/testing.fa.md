# تست دستی نسخهٔ آزمایشی روی ویندوز

## ساخت

با .NET 10 SDK روی ویندوز:

```powershell
dotnet build ProcessBlacklist.slnx -c Release
dotnet run --project tests/ProcessBlacklist.Core.Tests -c Release
dotnet run --project tests/ProcessBlacklist.Windows.Tests -c Release
dotnet run --project tests/ProcessBlacklist.Ui.Smoke -c Release -- ui-preview
```

برای اجرای برنامه، `src\ProcessBlacklist.App\bin\Release\net10.0-windows\ProcessBlacklist.exe` را باز کن. نسخهٔ مستقل از SDK در artifactهای CI قرار می‌گیرد.

## قواعد و Preview

1. برنامه باید با پایش متوقف و گزینهٔ Terminate خاموش شروع شود. هیچ قانون فعالی نباید خودکار اجرا شود.
2. یک پردازش آزمایشی از برنامهٔ خودت انتخاب کن. در ویندوزهای جدید Notepad ممکن است پردازش میزبان/نام متفاوت داشته باشد؛ نام را از همین جدول بردار.
3. Use selected name و Add rule را بزن. نام با و بدون `.exe` و حروف متفاوت باید به یک قانون Exact تبدیل شود؛ قانون تکراری نباید ذخیره شود.
4. Start preview را بزن. پردازش باید در Matches/Activity دیده شود و باز بماند. یک قانون Contains را هم در Preview بررسی کن.
5. Stop را بزن؛ Enable / disable را تست کن. قانون غیرفعال نباید Start را فعال کند اگر قانون فعال دیگری وجود ندارد.
6. نام پردازش را در فیلتر بنویس. انتخاب را نگه دار و هنگام توقف Refresh کن؛ اگر پردازش بسته شده، پردازش دیگری نباید جای انتخاب قبلی قرار بگیرد.

## Termination روی نمونهٔ آزمایشی

روی نمونه‌ای بدون دادهٔ ذخیره‌نشده تست کن. Start termination و End selected بستن اجباری هستند.

1. پس از بررسی Preview، Stop کن، Terminate را انتخاب و Start termination را تأیید کن. تنها نمونه‌های مطابقِ قابل بررسی باید بسته شوند.
2. دو نمونهٔ همان برنامهٔ آزمایشی را اجرا کن. Closed باید خروج‌های تأییدشده را جداگانه بشمارد.
3. Exact و Contains هم‌پوشان تعریف کن؛ تنها اولین قانون فعال باید مسئول همان پردازش باشد.
4. Stop را بزن و یک نمونهٔ جدید باز کن؛ نباید پس از توقف بسته شود.
5. پردازش خود ProcessBlacklist را در Preview مطابق یک قانون قرار بده. Activity باید Protected نشان بدهد؛ بستن آن مجاز نیست.
6. خطای دسترسی، پردازش خارج‌شده و هویت نامشخص باید نتیجهٔ روشن بدهند. شمارنده نباید برای درخواست ناموفق افزایش یابد.

## ذخیره‌سازی و رابط

- برنامه را ببند و باز کن؛ قوانین، enabled state و interval باید حفظ شوند، ولی پایش دوباره متوقف و Preview انتخاب‌شده باشد.
- Settings folder باید `%LOCALAPPDATA%\ProcessBlacklist` را باز کند. پس از پشتیبان‌گیری از فایل شخصی، JSON خراب را تست کن؛ فایل نباید خودکار پاک یا بازنویسی شود.
- Minimize to tray، نمایش دوباره، Stop از منوی tray و Exit را تست کن. Minimize پایش را ادامه می‌دهد؛ بستن پنجره آن را متوقف می‌کند.
- فرم را با Tab بررسی کن، کوچک کن و در Scale برابر ۱۲۵٪، ۱۵۰٪ و ۲۰۰٪ و High Contrast ببین که کنترل‌ها و وضعیت قابل خواندن باشند.
- پس از شروع Termination، Stop را حین بررسی بزن؛ برنامه باید منتظر پایان عملیات جاری بماند و اقدام بعدی را انجام ندهد. درخواست بستن صادرشده قابل بازگرداندن نیست.

نتیجه را با نسخهٔ ویندوز، معماری، حالت دسترسی معمول/مدیر، نام پردازش آزمایشی، مراحل و متن کامل خطا گزارش کن.
